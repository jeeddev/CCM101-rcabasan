# Laboratory Activity 5: Cloud Data Engineering with MinIO

## Mission Overview
In this mission, the focus shifts to cloud data engineering by deploying an S3-compatible Object Storage solution. The primary goal is to provision a MinIO server to handle large amounts of unstructured data, simulating a robust storage environment needed for a scalable photo-sharing application.

## Objectives
* Understand the distinctions between Block, File, and Object Storage infrastructures.
* Use Docker to launch a MinIO object storage container.
* Access and manage the deployed cloud service via its web console.
* Provision a storage bucket and perform a web-based data upload.
* Create structured technical documentation using Markdown format.

## Tools Used
* Docker / Containerization
* Ubuntu (KillerCoda Environment)
* MinIO Cloud Storage
* Markdown (.md)
* GitHub Portfolio

## Skills Learned
* Configuring isolated storage environments using Docker containers.
* Applying environment variables to enforce secure server credentials during deployment.
* Managing port forwarding (9000 and 9001) for API and UI access.
