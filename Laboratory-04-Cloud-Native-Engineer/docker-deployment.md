* `docker ps` - Lists all currently running containers in the environment to monitor active services.
* `docker stop my-nginx` - Gracefully stops the running container named "my-nginx" without deleting it.
* `docker ps -a` - Lists all containers, including those that are stopped or inactive, to verify current states.
* `docker rm my-nginx` - Completely removes the stopped container from the Docker environment to free up resources.
