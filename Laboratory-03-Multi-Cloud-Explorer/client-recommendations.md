* **Client A - Startup Company:** Google Cloud Platform (GCP). It offers cost-effective scaling for rapid growth. They could use Cloud Run, Firebase, and Cloud Storage.
* **Client B - University:** Microsoft Azure. It provides a seamless migration path for their existing Windows Server environment. They could use Microsoft Entra ID, Azure Virtual Machines, and Azure SQL.
* **Client C - AI Research Company:** Google Cloud Platform (GCP). GCP leads in machine learning hardware. They could use Compute Engine (with TPUs), Vertex AI, and BigQuery.
* **Client D - Global E-Commerce:** Amazon Web Services (AWS). AWS offers the massive maturity and auto-scaling needed globally. They could use EC2 Auto Scaling, Amazon CloudFront, and Amazon RDS.
