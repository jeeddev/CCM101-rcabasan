I learned how to properly manage user accounts, navigate directories, and extract vital system information using basic commands like `adduser`, `whoami`, `mkdir`, and `cat`[cite: 1]. Furthermore, setting up this GitHub repository taught me the true value of professional documentation and version control[cite: 1]. I know these fundamental skills in Linux and GitHub will be crucial not just for this semester, but for my future system development projects and career in IT. Overall, this mission successfully laid a solid foundation for my cloud computing journey[cite: 1].
